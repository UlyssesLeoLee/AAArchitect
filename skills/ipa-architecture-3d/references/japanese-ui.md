# 日本語 UI・情報設計ルール

- UI のアクションは同一文体・短い動詞に統一。例：「全体表示」「画像保存」「関係を表示」「詳細を閉じる」。説明文に「します。です。〜してください。」を無目的に連続させない。
- ラベルは名詞止め、支援テキストは必要なときだけ簡潔に。用途を示す見出しと同義説明を繰り返さない。
- View 名と図要素の命名は設計書と一致。用語表：コンポーネント、実行環境、信頼境界、データフロー、依存関係、監視、認証・認可、障害領域。
- 数字、単位、括弧、句読点を一貫した表記へ。時刻や日付は対象プロジェクトの記述形式に揃える。
- 省略表示は UI 上のみで許容。詳細パネルや表形式では完全な名称・責務・根拠を閲覧可能にする。
- 日本語の単語を英語の幅前提で機械改行しない。ラベルの描画幅、フォント、行間、表示段数、余白を実測する。
- View の切替ボタン、検索、選択、ズーム、凡例は視覚表現とテキストの二重伝達で認知負荷を下げる。
- 低視力・色覚多様性に配慮し、色だけで関係/分類を判定させない。テキスト一覧は WebGL に依存させない。
