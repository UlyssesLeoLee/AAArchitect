# 多语言生成规范（默认中文）

## 语言参数

- 默认 `--lang zh-CN`，所有新项目文案、网页组件、轴刻度、审查结论、说明均为**简体中文**。
- `--lang ja-JP`：面向日本市场，遵循自然的短 UI 标签、文体一致、名词结句优先、避免无意义的「します。です。～してください。」混用。正式设计文件以明确、统一的书面体呈现。
- `--lang en-US`：面向英语审查者，使用简洁技术英文，保持术语一致。
- 自定义语言（如 `fr-FR`）时，必须同时给 `meta/nodes/views` 添加文本 `i18n.fr-FR` 和 `assets/viewer/src/i18n.js` 的 UI 字典，之后才允许 `--lang fr-FR`。缺失翻译禁止静默回退。

## 单一事实模型

`architecture.json` 的 ID / 关系 / 属性结构共享一份，i18n 仅保存多语显示文本。分类字段如 `trustZone` 对应的类目翻译，应与该 View 的 `orderBy` 同步翻译。不要通过翻译修改协议、关系类型、拓扑、证据状态。

## 禁止事项

- 原始数据中文、网页按钮日文、审查说明英文的混搭。
- 使用占位符翻译但装作完整本地化。
- 将中文本地化后的术语改写为与证据不符的系统组件名称。
- 使用补足边界和容灾的“技术常识”替代真实来源。
